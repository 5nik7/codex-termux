roots, and loopback fixture servers, executed natively on Termux. It checks real

real accounts or establish model behavior. The release suite installs only into
a disposable test prefix, never the installed wrapper's prefix.

`groff` is unavailable: local manual rendering was skipped. No dependency was
installed to bypass this limitation. The opt-in real-runtime transport smoke,
real-account acceptance, performance benchmarks, hosted download checks, and
CI were not rerun during this preparation. The smoke tool's version reference
now reads VERSION; only its Python syntax was checked here.
