# codex-termux 0.4.3

This maintenance release improves Zsh completion grouping throughout the
wrapper command tree.

Commands, options, and enumerated values use separate standard Zsh tags,
including nested `manage server` and `manage config` routes and mixed
root/connect menus. Shell completion preferences can style each group while
inserted words stay literal. Existing description styles remain authoritative;
the adapter does not change global styles or require Dots.

An automatic audit walks the advertised completion tree, checks semantic tags,
and compares Zsh candidates with Bash. It runs alongside the existing actual
Bash/Zsh Tab-insertion tests in offline verification and CI. The maintenance
guide, output coverage matrix, manual, and repository skill document this
contract.

All public commands, flags, backend filtering, and forwarding boundaries are
retained. Service management, native Termux DNS/proxy behavior, authentication,
and package/runtime management remain compatible.

## Upgrade and validation

After publication, use `codex-termux manage self-update` to update the wrapper.
`manage update` separately manages the Codex npm runtime. Existing credentials,
configuration, runtimes, and service definitions are preserved.

The release contains 15 assets. `SHA256SUMS` covers 11 package payloads;
`RELEASE-SHA256SUMS` also covers the source archives and package manifest.
See `VALIDATION.md` in the source bundle for measured checks and platform limits.
Tests use owned roots and fake credentials; host-shell theme rendering and
live-account acceptance remain separate checks. Publishing does not install
this version locally or change the running service.
