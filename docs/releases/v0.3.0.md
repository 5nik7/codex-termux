# codex-termux 0.3.0

- More colorful, terminal-aware help with the existing phone-sized ASCII header.
- A complete `man codex-termux` manual and installed Bash/Zsh completion.
- Local or curl/wget package installation, version comparison, checked upgrades,
  backups, and confirmed uninstallation.
- `manage self-update` updates the wrapper, completion, and manual.
  `manage update` continues updating the Codex npm runtime.
- Disposable regression coverage, deterministic release assets, and a release guide.

Install or upgrade from the extracted source bundle:

```bash
bash install.sh --source . --dry-run
bash install.sh --source .
```

After publication, the release installer is also available at:

```bash
curl -fsSL https://github.com/5nik7/codex-termux/releases/latest/download/install.sh | bash
```

The package installer asks before changing files. Same wrapper version is a
no-op; older offers do not downgrade. Existing recognized standalone wrappers
are backed up. Codex configuration, authentication, npm runtimes, and shell
startup are preserved. Uninstall removes owned public entries and retains
private recovery copies/history.

`SHA256SUMS` covers the runtime payload; `RELEASE-SHA256SUMS` also covers the
source ZIP/tar. These establish checksum integrity under the trust placed in
GitHub and this publisher, not independent signing.

See `VALIDATION.md` in the source archive for actual evidence and limitations.

publishing the draft. Do not label modeled Linux tests as Android execution.
