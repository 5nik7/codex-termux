# Historical 0.2.0 evidence

These files retain the original 0.2.0 validation, raw measurements, and installation
record from the repository's first commit. They describe that older artifact;
they are not fresh test results for 0.3.0.

The historical `SHA256SUMS` uses the original 0.2.0 archive's root-relative paths.
Do not run it against the current checkout. The current install manifest is
`PACKAGE-SHA256SUMS` at the repository root, and current evidence is in
[VALIDATION.md](../../../VALIDATION.md).
